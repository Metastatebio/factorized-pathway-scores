- Fresh-environment tests: 40 passed.

- Public source checksum failures: 0.
- Full analysis wall time: 37 minutes 34 seconds from first verified input through synthesis.
- Declared analysis outputs compared: 83.

- Raw source files tracked for distribution: 0.
- Final decision: `ROBUST_HUMAN_STRUCTURAL_AND_REACTION_TOPOLOGY_SIGNAL`.

The initial audit found four non-scientific portability differences: PDF creation timestamps in
three vector figures and absolute local paths in the figure source index. The exporter was changed
to suppress volatile PDF timestamps, emit repository-relative paths, and use a canonical semantic
hash for run manifests. The figures and source index then regenerated byte-identically.

Run manifests remain intentionally non-byte-identical because they record completion timestamps
and local execution paths. Their declared output checksums and all manuscript-facing quantitative
outputs are identical.

Release 1.0.1 changes only the package version and the pinned `setuptools` build backend from
80.9.0 to 83.0.0 to address GHSA-h35f-9h28-mq5c. A fresh environment installed the revised lock,
built the wheel, verified all 14 artifact manifests, passed all 40 focused tests and reproduced the
same 83 declared scientific-output checksums. No analysis dependency, configuration, source input
or scientific artifact changed from the full clean-room run.
